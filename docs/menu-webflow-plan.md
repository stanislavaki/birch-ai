Site-level кастом-код сайта на нав не влияет (проверено: все правила и скрипты целятся в чужие классы; `initMobileMenu` старого нава внутри нового не находит своих элементов и молча выходит).

## Финальные спеки (из прототипа)

- **Высоты** (`--nav-height` остаётся источником правды для sticky/embeds, ничего не переписываем):
  - десктоп: воздух 6 + пилла 92 (5.75rem) + воздух 6 = `--nav-height: 6.5em` (не меняется);
  - мобилка: пилла с полями 12px; компонент скоупит переменную: `@media (max-width:767px) { :root { --nav-height: 5.5em } }` → пины на 12px под пиллой.
- **Стекло** (пилла, панель, мобильная карточка = один материал):
  - fill тёмная `rgba(63,63,63,.6)`, светлая `rgba(211,209,224,.4)` (#D3D1E0);
  - backdrop: `blur(30px) saturate(0.8) brightness(1.15)` — пилла и панель одинаково;
  - мобильная открытая карточка НЕпрозрачная: тёмная `#292929`, светлая `#fff`; пилла в открытом состоянии красится в цвет карточки; scrim за карточкой: тёмная `rgba(13,13,18,.6)`, светлая `rgba(255,255,255,.5)` + blur 12.
- **Геометрия десктопа**: корпус пиллы = контентная колонка `.container` (80rem, гаттеры 1.5rem) + рамка-инсет (высота пиллы − высота кнопки)/2 = 10px; лого и Get started стоят на краях контентной сетки; панель 30.75rem, паддинг 8, радиус 20 (концентрично 12+8), колонка заголовков 10.5rem, строки py 16, панель выровнена по левому краю текста триггера.
- **Типографика**: тексты меню 0.9rem/14.4 (как на бою); трекинг ярусами: 24px → 0em, 16px-ярус → 0.01em, 12px → 0.01em; вес 600; CTA-текст оптически центрован по полосе cap-height (на 56px кнопке = padding-bottom 1px).
- **Ховеры**: общий токен — белый 10% (тёмная) / белый 70% (светлая); в сабменю плашка-слайдер ездит между пунктами (320ms cubic-bezier(.22,.9,.24,1)), описание набирает контраст; Book demo/Log in — плашки впритык (текстовый зазор 28 = зазору пунктов); Get started: чёрный текст, ховер indigo #4450F2 + белый.
- **Теги**: New — жёлтый, rotate −18°, 0.7rem; Soon — тот же стиль в приглушённых цветах (`--nav-soon-*`); зазор заголовок↔тег 0.2rem; отрицательный margin-bottom −0.35em (теги не раздувают строку); disabled-пункт: приглушение + `pointer-events:none`.
- **Мобилка**: карточка-враппер 12px от краёв, влетание снизу (translate, 380ms cubic-bezier(.32,.72,0,1), радиусы сохраняются), аккордеон «один открыт», автораскрытие раздела активной страницы + активный пункт в зоне видимости, бургер 2→4 точки и нейтральный круг в открытом состоянии (белый/`#DBDAE2`), кнопки-чипы серые (`#3F3F3F`/`#DBDAE2`), зазоры кнопок 8, до краёв 12, кегль CTA 24.
- **Активные состояния**: точка у пункта (по слову, не по боксу) и у пункта сабменю; URL-матчинг по префиксу (`/case-studies/*`), у групп — список URL.
- Контент финальный — уже в прототипе (тексты Даши, Routines = Soon без ссылки).

## Архитектура в Webflow

- **Верхний уровень** — компонент `super-navigation-component` (id `33e783c9-057c-0437-6c4c-ea28f08e4679`, 78 инстансов). Пропы ПЕРЕИСПОЛЬЗУЕМ (не создаём новые!) — тогда переживут замену все пер-страничные оверрайды (напр. hub: `?gateway=true`). Ключевые: `Get started url`, `color-mode` (тема страницы), mob title. MCP пропы не умеет — привязка руками в Designer (~5 шт.).

- **JS-поведение** (ховер-интент, плашка-слайдер, аккордеон, влетание, active-матчинг) — embed внутри компонента; классы `.is-open` для дизайнера (открытые состояния видны на холсте).
